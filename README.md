# API de Gerenciamento de Pedidos

Projeto prático avaliativo de Tópicos Avançados em Sistemas de Informação II.

API REST desenvolvida com Node.js, Express e JavaScript para gerenciar pedidos de uma pequena loja.

## Requisitos

- Node.js 18 ou superior
- npm

## Instalação inicial

```bash
npm install
npm start
```

O servidor utiliza a porta 3000 por padrão. O armazenamento dos pedidos é em memória.
